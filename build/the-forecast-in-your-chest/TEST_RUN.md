# Concept Engine v3 test run — The Forecast in Your Chest

This is the first end-to-end test of the helpful editorial intelligence layer.

## Creative output

- 24 short scenes
- 337 spoken words
- approximately 160 seconds at 2.1 words/second
- one ruling metaphor: emotion as a body-informed weather forecast
- science labeled emerging inside the narration
- explicit evidence boundary
- grounding rendered in the final scenes
- final line is a viewer-owned question
- motion-first visual grammar
- human-coded scene ratio below half
- no required hero stills in the script plan

## Help transformation output

`help-kit.json` contains:

- daily invitation
- four-field belief examiner
- relationship conversation prompt
- 60-second non-clinical grounding audio
- moderated community prompt
- educator discussion card

## What the test is meant to prove

The engine should be able to make emotionally useful work without:

- denying the reality of emotion
- implying symptoms are chosen
- presenting an emerging model as settled science
- offering medical treatment
- using fear, identity or certainty as the engagement lever
- asking the viewer to adopt the channel's verdict

## Success condition

A successful response is not merely agreement. The useful signals are reflection,
application, curiosity, constructive disagreement and a viewer-owned revision test.
